**Focus:** Flutter, Dart, iOS, UI/UX, Architecture

### Course & Learning Platform

A full learning platform centered around courses, teachers, authentication, administration, and structured educational content.

The project includes an administration system and backend architecture designed around secure authentication, database relationships, and role-based access.

**Focus:** Flutter, Supabase, Authentication, Database Design, REST APIs

---

### Smart Home System

A Flutter-based IoT application for controlling connected devices through Wi-Fi.

The system integrates Flutter with ESP8266 microcontrollers, relay modules, and Firebase Realtime Database to provide remote device control and monitoring.

**Focus:** Flutter, Firebase, ESP8266, Arduino, IoT

---

### TubeMind

A learning application focused on consuming and organizing educational video content.

The project explores video integration, playlist-based learning, application architecture, and user-focused interfaces.

**Focus:** Flutter, Dart, Video Integration, State Management

---

### LinguaFlow

A language-learning application designed to support vocabulary development and structured language learning.

The project explores educational UX, content organization, local data handling, and application architecture.

**Focus:** Flutter, Dart, Education, Local Persistence

---

### Discount & Store Platform

A location-based marketplace concept focused on discovering stores, products, and offers through a modern, content-driven experience.

The project explores backend architecture, database design, location-based functionality, and modern mobile UI.

**Focus:** Flutter, Supabase, Database Design, REST APIs, UI/UX

---

### Doctor Appointment Administration System

An administrative application designed for managing doctors, appointments, users, and related healthcare data.

The project provided experience with structured dashboards, authentication, database relationships, and administrative workflows.
